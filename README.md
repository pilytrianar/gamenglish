# Gamenglish

Aplicación web educativa desarrollada con ReactJS y Express para la enseñanza del inglés en niños.

## Tecnologías utilizadas

### Front-end
- ReactJS
- React Router
- Axios
- Hooks
- Context API

### Back-end
- Node.js
- Express
- Swagger

## Funcionalidades

- Navegación entre páginas
- Consumo de API REST
- Formulario de contacto
- Documentación con Swagger
- Gestión de estado con Hooks

## Ejecución del proyecto

### Front-end

```bash
cd frontend-react
npm install
npm run dev
```

### Back-end

```bash
cd backend
npm install
npm run dev
```
